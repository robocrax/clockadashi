gpmc-daemon

github.com/robocrax/gpmc-daemon · Google Photos Sync Daemon

Overview & Quota Preservation Strategy

gpmc-daemon is a headless continuous backup daemon written for Linux servers and NAS units. It observes local media directories and uploads them to Google Photos utilizing the platform's free "Storage Saver" compression parameters so they do not consume your storage limits.

inotify Watcher

Detects newly added photos and videos instantaneously with low CPU footprint.

Zero-State Deduplication

Maintains an internal SQLite hash database to ensure zero duplicate uploads.

Headless OAuth2

One-time browser authentication token flow with automated refresh cycles.

Quickstart & Installation

# 1. Clone the repository
git clone https://github.com/robocrax/gpmc-daemon.git
cd gpmc-daemon
# 2. Compile binary via Makefile
make build
# 3. Initialize daemon watching target path
./gpmc-daemon --watch-dir /mnt/storage/photos --config ~/.config/gpmc/config.json

heartbeats-ping-sidecar

github.com/robocrax/heartbeats-ping-sidecar · Monitoring Sidecar Utility

Purpose & Operational Design

heartbeats-ping-sidecar is a compiled, minimal Go binary container designed to monitor isolated network nodes (such as IoT gateways, home automation hubs, or isolated database servers) without installing heavy telemetry agents. It tests connectivity via ICMP or TCP handshakes and sends an HTTP pulse to external monitors (Healthchecks.io, BetterStack) strictly when all checks return successfully.

Docker Compose Example

version: '3.8'
services:
sidecar:
image: ghcr.io/robocrax/heartbeats-ping-sidecar:latest
restart: always
environment:
- TARGET_HOST=192.168.1.50
- HEARTBEAT_URL=https://hc-ping.com/your-uuid-token
- PING_INTERVAL_SEC=30
